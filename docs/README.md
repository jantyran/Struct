# Struct Project Docs

この `docs` ディレクトリは、このリポジトリの目的・構造・実装フローを、人と AI の両方が素早く把握できるようにするための共有ドキュメントです。

## まず読むもの

- `architecture.md`
  - プロジェクト概要
  - ディレクトリ構成
  - データモデル
  - API と画面の責務
  - AI 生成フロー
  - 実装上の注意点

## このプロジェクトの要約

Struct は、マーケティング施策を「再利用できる構造」として保存し、以下の 3 層情報を元に AI で成果物を生成する Next.js アプリです。

- Global Assets
  - 会社情報、ブランドボイス、製品情報など、全案件共通の情報
- Project Core
  - 案件名、種別、ターゲット、期間、予算、チャネル、概要
- Project Custom
  - 案件ごとの追加フィールド。URL 型は本文抽出も可能

生成対象は LP、DM、SNS 投稿、広告コピー、メール、社内報告書です。

## ドキュメント運用方針

- 実装を読んで確認できた内容を優先して記述する
- 推測で埋めず、未確認事項は未確認として書く
- 実装変更時は `docs/architecture.md` も更新する
