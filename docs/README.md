## 現在のアプリ要約

Struct は、ユーザー単位の Global Assets と、所有者およびメンバーで共有するプロジェクト情報をもとに、マーケティング成果物を生成する Next.js アプリです。

主要な構成要素は以下です。

- 認証
  - メールアドレスとパスワードで登録、ログイン
  - JWT を Cookie に保存
- Global Assets
  - 会社情報、ブランドボイス、ブランドガイドライン、製品情報
- Project Core
  - 案件名、種別、ステータス、ターゲット、期間、予算、チャネル、概要
- Project Custom
  - 案件ごとの追加フィールド
  - URL 型は本文抽出に対応
- Collaboration
  - オーナーが招待 URL を発行
  - 招待先ユーザーが参加して共同編集

生成対象は以下です。

- LP 構成案
- ダイレクトメール
- X 投稿
- LinkedIn 投稿
- 広告コピー
- メールマガジン
- 社内報告書
