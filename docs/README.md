## 現在のアプリ要約

Struct は `MKTキャンペーン運用デスク` として、キャンペーンやイベント単位の進行管理、情報集約、生成コンテンツ運用をまとめる Next.js アプリです。

## 起動運用

- `3002`
  - 開発確認用
  - `npm run dev`
  - ビルドなしで変更を即時反映して確認する
- `38427`
  - 本番確認用
  - `npm run build && npm run start`
  - ビルド済みの安定版を確認する

補足:

- 外部共有前提のURL生成では `NEXT_PUBLIC_BASE_URL` を使うため、通常は `38427` 側のURLを設定する
- 開発用のビルド出力は `.next-dev`、本番用のビルド出力は `.next` を使い分ける
- 3002 と 38427 は同時に動かしてよい

主要な構成要素は以下です。

- 認証
  - メールアドレスとパスワードで登録、ログイン
  - JWT を Cookie に保存
  - システムロールで管理系機能へのアクセスを制御
- Global Assets
  - 任意のオブジェクトを作成
  - オブジェクトごとに項目とレコードを管理
  - `参照` / `複数参照` による他オブジェクト参照
- プロジェクト設定
  - 種別ごとにフェーズ、フィールド、生成コンテンツ利用範囲を定義
  - 項目定義と UI 配置定義を分離
  - 項目設定では項目情報のみを管理
  - セクション設定では項目順、所属セクション、列幅をドラッグ＆ドロップで調整
  - `グループ` / `繰り返しグループ` を含む構造化フィールドを定義
- プロジェクト
  - 種別とフェーズに沿った案件管理
  - Path UI による進行表示
  - Global Assets 参照、グループ入力、生成コンテンツ作成
  - 主担当者、プロジェクトメンバー、プロジェクトロールを管理
- ユーザー / ロール管理
  - ユーザー管理権限を持つユーザーは、ユーザー追加・削除・プロフィール・システムロールを管理
  - システムロールはシステム全体の管理権限を定義
  - プロジェクトロールはプロジェクト内の表示・編集・メンバー管理権限を定義
- 生成コンテンツ設定
  - チャネル、テキスト形式、トーン、必須要素、構成例、指示を管理
- AI 設定
  - Gemini / OpenAI / Anthropic を切り替え
  - モデル、Base URL、API キーをユーザー単位で保持

## 今後の実装予定

- `Todo`
  - 担当者、開始日、締切日、優先度、フェーズ、親子構造を持つ実行管理の起点
  - 登録済みユーザーとプロジェクトメンバーを担当者候補にする
- `KANBAN`
  - Todo のステータスをカードとして表示
  - 担当者フィルタとプロジェクト内/横断表示を想定
- `WBS`
  - Todo の開始日・締切日からガント表示を自動生成
  - バー操作で日付編集し Todo に反映する構想
- `レポート`
  - プロジェクトに紐づく成果レポート
  - KPI、背景、学び、インサイト、PDF出力を想定
- ファイル添付
  - 優先度は低く、将来検討

## 現在合意している設定UIの整理

- `項目設定`
  - 管理対象は項目そのものの情報
  - ラベル、キー、型、選択肢、参照先、子項目定義を扱う
- `セクション設定`
  - 管理対象は UI 上の配置
  - セクション順、どのセクションにどの項目を置くか、`1列` / `2列` を扱う
  - 未配置ボックスと各セクション間で項目をドラッグ&ドロップできる形を前提とする
  - 未配置項目と配置済み項目は色分けして視認できるようにする

## 直近実装メモ

- ユーザー管理
  - `/settings/users`
  - `manage_users` 権限を持つユーザーが、ユーザーの追加・削除・表示名・アバター・システムロールを変更できる
  - 最後のシステム管理者と自分自身は削除できない
- システムロール管理
  - `/settings/roles`
  - `manage_system_roles` 権限を持つユーザーが、システム全体の管理権限を定義できる
  - 初期ロールは `システム管理者`、`マネージャー`、`一般ユーザー`
- プロジェクトロール管理
  - `/settings/project-roles`
  - `manage_project_roles` 権限を持つユーザーが、プロジェクト内の表示・編集・メンバー管理などを定義できる
  - 初期ロールは `プロジェクト管理者`、`メンバー`、`ゲスト`
- プロジェクトメンバー管理
  - プロジェクト詳細の `メンバー` タブで管理
  - メール入力招待ではなく、システム登録済みユーザーから選択して追加する
  - 主担当者も同じ `メンバー` タブで変更する
